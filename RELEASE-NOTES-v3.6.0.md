# Main River Cottage Planner v3.6.0 — Operational Polish

## Navigation
- Removed the Hosting tab and route.
- Hosting-style work such as deck building now belongs in Activities.

## Dashboard
- Added Upcoming Activities.
- Activity cards show date, time, location, participant count and linked meal count.
- Replaced the Hosting quick link with Activities and Accommodations.

## Base Grocery List
- Fixed zero-quantity Base List items appearing on the Trip Grocery List.
- Base List rows are now always editable inline.
- Removed the redundant pencil/save interaction.
- Added `Add Base List Item`.
- Custom Base List items can be deleted.
- Base List edits update the Trip Grocery List immediately on the same device.
