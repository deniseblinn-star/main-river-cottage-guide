# Main River Cottage Planner v1.6

## Added
- Add Grocery Item button on Trip Shopping
- Manual items saved in the browser on the current device
- Fields for name, quantity, unit, category, store, notes and gluten-free
- Manual items can be checked, deleted and grouped by store/category
- Source labels distinguish Recipe / planned, Base list and Manual items
- Manual items can be marked for future merging with matching recipe ingredients

## Not included yet
- Automatic recipe scaling based on attendance
- Automatic duplicate merging and unit conversion
- Cloud syncing of manual grocery additions between family devices
