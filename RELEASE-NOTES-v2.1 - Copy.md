# Main River Cottage Planner v2.1 — Unified Trip Grocery List

## Changed
- Removed stores, preferred stores and shopping runs.
- Recipe, Base Cottage and added items now appear in one Trip Grocery List.
- The list is organized by category rather than retailer.

## Added
- Views: All, Outstanding, Purchased, Unassigned and By Person.
- Any user may assign any grocery item to any guest.
- Purchased status works for all three grocery sources.
- Shopping notes can be added to every item.
- Base Cottage List remains editable as the reusable template.

## Current limitation
- Changes remain browser-local until shared cloud storage is connected.
