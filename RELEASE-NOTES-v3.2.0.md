# Main River Cottage Planner v3.2.0 — Phase 3 Meal Planner

## Added
- Six date-specific Meal Slots for every date in the active Overall Event.
- Editable time for Breakfast, Brunch, Lunch, Early Snack, Dinner and Late Snack.
- Automatic attendance for Lunch, Early Snack, Dinner and Late Snack based on arrival/departure.
- Breakfast and Brunch begin unassigned.
- Manual attendee additions and exclusions for every Meal Slot.
- Meal planning modes: Recipes, Restaurant, Simple plan and Not planned.
- Multiple Recipe Catalogue recipes can be assigned to the same Meal Slot.
- The same recipe can be assigned to multiple Meal Slots independently.

## Changed
- Weekly Planner is now Meal Planner.
- Daily Planner is now Daily Meals.
- Recipe categories describe the recipe type (Main, Side, Salad, etc.), not the meal time.

## Not yet included
- Phase 4 will make date-specific Recipe Assignments drive grocery scaling. The existing grocery engine remains unchanged in this release.
