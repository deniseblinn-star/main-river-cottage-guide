# Main River Cottage Planner v3.1.0 — Real Phase 2

This release implements the Event Engine in application code.

## Added
- Overall Events route and sidebar navigation
- Create, edit, select and delete Overall Events
- Active-event selector in the top bar when multiple events exist
- Permanent Profile Library
- Event-specific Attendance with arrival/departure date and time
- Needs-accommodation flag
- Add/remove profiles from the active event
- Browser-local persistence and seed migration from the original guest list

## Not yet connected
- Weekly/Daily Planner still use the original Main River data until Phase 3
- Groceries still use the current grocery engine until Phase 3/4
- Beds are Phase 4
