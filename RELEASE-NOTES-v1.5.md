# Main River Cottage Planner v1.5

## Added
- A separate **Base Cottage List** inside Groceries
- Checkable base items with purchase progress
- Editable quantity, unit and notes fields
- Edits and checkmarks save locally on the device
- Seeded Breakfast & Bakery items:
  - Cereal — 2 boxes — Honey Nut Cheerios and Corn Pops
  - Bagels
  - English muffins
  - Regular white bread
  - Gluten-free white bread
  - Gluten-free hamburger buns
  - Peanut butter and jam
- Added dairy, coffee, tea, fruit, snacks and basic backup items

## Unchanged
- Existing trip grocery list remains intact
- Recipe-driven automatic scaling is not yet enabled in this release
