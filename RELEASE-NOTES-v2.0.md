# Main River Cottage Planner v2.0 — Editable Recipe Imports

## Added
- Two URL import test cases: Allrecipes Classic Caesar Salad and HowToBBQRight Whole Beef Tenderloin
- Every imported field remains editable
- Edit button for saved custom recipes
- Editable servings/yield, ingredients, instructions, times, source and tradition
- Equipment/method tags including Smoker
- Source URL retained only for attribution and reference

## Important
- URL import is a prefill, never a locked copy.
- Recipes without URLs can still be created manually.
- Browser-local storage remains the current persistence method.
