# v3.7.7 — Daypart Calendar

- Calendar now uses Morning / Afternoon / Evening instead of hourly rows.
- Breakfast + Brunch → Morning.
- Lunch + Early Snack → Afternoon.
- Dinner + Late Snack → Evening.
- Activities are placed by start time, with exact times retained in smaller text.
- Weather and on-site attendance stay in each day header.
- Week at a Glance is unchanged.
- No planner data is migrated or rewritten.
